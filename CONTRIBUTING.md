## Before contributing

- Open an issue before large product, architecture, protocol, or dependency changes.
- Keep human UI and MCP operations on the same domain services.
- Preserve English and Simplified Chinese localization key parity.
- Run `make format`, `make localization-check`, `make lint`, `make build`, and `make test` before submitting a pull request.
- Do not add generated build products, secrets, API keys, screenshots containing private data, or machine-specific paths.
